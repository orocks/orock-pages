Solar-Powered ESP32 Weather Station via LoRa

Research compilation: curated resources and BOM for a terrace-mounted ESP32 weather station communicating via LoRa to a local gateway.

1. ESP32 Deep Sleep & Power Optimization

Core techniques for getting months of battery life: timer wake-ups, RTC memory, ULP coprocessor, and power budgeting.

  • ESP32 Deep Sleep: Ultra-Low Power IoT Sensor Node Build — Zbotic (2026). Comprehensive guide covering wake sources, RTC memory, sensor wiring, firmware, and real battery life estimation.
  • Power Management and Deep Sleep — SiliconWit. Covers deep sleep modes, ULP coprocessor programming, RTC memory persistence, wake sources, and solar-ready weather node optimization.
  • ESP32 Deep Sleep Battery Sensors (2026 Guide) — Esp32.co.uk. Explains why USB-powered designs fail on battery, ESPHome deep sleep config, ADC for battery monitoring, and practical low-power design patterns.
  • ESP32 Deep Sleep Guide: Extend Battery from Days to Months — SolderHub. Practical tips: RTC_DATA_ATTR usage, Serial.flush() before sleep, wake-on-timer vs GPIO.
  • Deep Sleep Low Power Optimization on ESP32 Dev Boards — ESP Boards Dev. Covers light sleep vs deep sleep, sensor wake-up capabilities, and balancing responsiveness with power consumption.
  • Low-Power-Arduino Sketch for Weather Station — GitHub Gist. Working sketch that wakes every N microseconds, reads sensors, transmits, sleeps.

2. Solar Power & Battery Management

  • Power ESP32 with Solar Panels and Battery — Random Nerd Tutorials. TP4056 charger, LiPo battery, level monitoring, caveats about load connections.
  • Solar Power for ESP32: MPPT and Battery Charging Circuit — Zbotic. TP4056 vs MPPT, 6V solar panel wiring, LiFePO4 vs LiPo considerations.
  • Powering ESP32 with solar + LiFePO4 — Home Assistant Community. Discussion on LiFePO4 for outdoor use (better thermal stability vs LiPo).
  • Best Solar Charging Modules for IoT (Buying Guide) — Microcontrollers Lab (2026). Compares TP4056, BQ25570 energy harvester, dual-USB solar managers, and LiFePO4-matched chargers.
  • Solar Powered WiFi Weather Station V2.0 — Hackaday.io. Real build logs with TP4056, 18650, and solar panel. Lessons learned from actual deployment.

3. LoRa Communication (ESP32 → Gateway)

  • ESP32 LoRa without LoRaWAN — Nodrix. Covers point-to-point LoRa, duty-cycle limits, honest range expectations, and why skipping LoRaWAN is often the right choice for a custom setup.
  • ESP32 LoRa Reliable Link — GitHub (rusilveira). Implements ACK, CRC16, and sequence control on top of LoRa for reliable delivery.
  • ESP32 LoRa 1-CH Gateway — SparkFun Learn. ESP32 LoRa board as a gateway. Good for the server-side implementation.
  • ESP32S3 LoRa: Setup, Range & Meshtastic — Seeed Studio Blog. 2026 overview of ESP32 LoRa capabilities, Meshtastic mesh networks, and practical range considerations.
  • ESP32 LoRa Remote Sensor Node for Home Assistant — Esp32.co.uk. Node and gateway design, MQTT topics, YAML sensors, and reliability tips for outdoor garden monitoring.

4. LoRa Module & Antenna Selection

  • SX1262 vs SX1276: Which LoRa Module Is Better? — Mozelectronics. SX1262 for new designs (better sensitivity, lower power); SX1276 if maintaining existing designs.
  • LoRa Module: SX1276 vs SX1262 vs SX1280 Compared — PCBSync. Benchmarks, sensitivity, data rates, and when to use each module.
  • SX1276 LoRa: Range, Sensitivity & Spreading Factor — Zbotic. Realistic range expectations at +20 dBm, spreading factor tradeoffs, antenna height impact.
  • LoRa RF Module Sensitivity Benchmarks — IC Online. Field test data for SX1262 vs SX1276, emphasizing power supply, antenna, and protocol design.

Core Electronics

MCUESP32-WROOM-32 or ESP32-C3ESP32 for Wi-Fi backup; ESP32-C3 for lower deep-sleep current (~6µA)
LoRa ModuleSX1262 (Ra-02 module)Better sensitivity (-165 dBm) and lower RX current vs SX1276
Environmental SensorBME280Most reliable: ±1 hPa pressure, ±3% RH. Avoid cheap DHT11/DHT22
Wind Speed SensorReed-switch anemometer or Davis 6410Davis = industrial grade. Reed-switch = budget but reliable
Wind DirectionPotentiometer-based vane or HMC5883LPotentiometer: simpler. HMC5883L: no moving parts
Rain GaugeTipping-bucket (DFRobot / PMS-G010)Mechanical, not IR-based (more reliable outdoors)
UV SensorVEML6075 (I2C)UV index measurement
Solar ChargerTP4056 module (with protection)For 1S LiPo/18650. For LiFePO4: use a LiFePO4-matched charger
Boost ConverterMT3608 or AP64532 step-upIf ESP32 3.3V rail needs more current than battery provides directly

Battery18650 Li-ion (2000-3500 mAh) or LiFePO4 18650LiFePO4 for outdoor thermal stability. 3500 mAh gives months of sleep cycles
